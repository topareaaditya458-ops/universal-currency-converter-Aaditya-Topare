# 💱 Universal Currency Converter

A simple and interactive currency converter built with Python and Streamlit. It allows users to convert amounts between different currencies using exchange rate data from the Frankfurter API.

## ✨ Features

- 🌍 **Multiple Currencies:** Choose from the supported currencies available through the API.
- 💰 **Currency Conversion:** Convert any positive amount from one currency to another.
- 🔄 **Swap Currencies:** Quickly switch the source and target currencies.
- ⚡ **Quick Amounts:** Select preset amounts for faster conversions.
- 📊 **Conversion Details:** View the exchange rate and converted amount.
- 🔄 **Automatic Updates:** Fetches exchange rate data from the API.
- ⚠️ **Error Handling:** Displays helpful messages if the API is unavailable or a request fails.
- 📱 **Interactive Interface:** Simple and user-friendly interface built with Streamlit.

## 🛠️ Technologies Used

- **Python** – Application logic
- **Streamlit** – Web interface
- **Requests** – API requests
- **Frankfurter API** – Exchange rate data
